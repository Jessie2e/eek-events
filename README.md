# EEK Events — Squarespace Main Character concept

A responsive, interactive homepage concept for EEK Events built to be portable into Squarespace 7.1.

## Files
- `index.html` — standalone local preview.
- `eek-squarespace-codeblock.html` — single-block Squarespace reference version.
- `custom-css.css` — split-install CSS.
- `footer-js.js` — split-install JavaScript.
- `STYLE-DIRECTION.md` — the evolved mini style guide / creative direction.
- `SQUARESPACE-INSTALL.md` — install and production notes.
- `assets/` — prototype images extracted from the EEK planning deck supplied for this project.

## Built-in sections
Hero / Main Character positioning • real-event collage • wedding campaign carousel • package cards • interactive Wedding Vibe Forge • EEK/team positioning • conversion CTA.

## Important
The three named wedding case studies are **not** using random images and pretending they are those couples. They use art-directed placeholders until the Caroline + Noah, Mike + Sara, and David + Diana image sets are added.
